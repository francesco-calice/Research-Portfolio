# Modelling Type Ia Supernova Rates in Cosmological Simulations

## Overview

This repository documents an Undergraduate Research Opportunities Programme (UROP) project completed at Imperial College London under the supervision of Dr Eleni Tsaprazi.

The project investigated whether large cosmological simulations could be used to generate realistic synthetic populations of Type Ia supernovae. I developed a Python rate-modelling pipeline connecting simulated galaxy properties and star-formation histories to expected supernova rates, applying it to approximately 150 million galaxies across multiple semi-analytic galaxy-formation models.

## Project information

* **Institution:** Imperial College London
* **Programme:** Undergraduate Research Opportunities Programme (UROP)
* **Supervisor:** Dr Eleni Tsaprazi
* **Period:** January–March 2025
* **Research area:** Type Ia supernovae, computational cosmology and statistical modelling

## Work completed

* Processed galaxy catalogues containing approximately 150 million simulated galaxies using Python and SQL.
* Implemented both empirical A+B rate models and prescriptions based on integrated star-formation histories.
* Applied Poisson sampling to generate synthetic Type Ia supernova populations.
* Compared predicted supernova rates and host-galaxy morphology distributions across the SAG, SAGE and GALACTICUS galaxy-formation models.
* Presented the results at an international supernova and cosmology teleconference.
* Authored a summary report, with findings from the project subsequently incorporated into a grant proposal.
